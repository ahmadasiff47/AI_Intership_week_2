Enterprise AI Copilot with Function Calling 🚀

An intelligent AI Assistant built using Python and Groq (`llama-3.3-70b-versatile`) that dynamically executes structured tools based on user intent via Function Calling.

 🌟 Features & Integrated Tools
- 🗄️ SQL Query Generator: Converts natural language requests into optimized SQL queries.
- 📩 Email Drafter: Generates professional email drafts for communication.
- 📊 Report Generator: Summarizes progress, challenges, and key achievements into dynamic reports.
- 🌐 Internet Search Orchestrator:Triggers live web search workflows for real-time information.
- ⚡ Dynamic Tool Execution:Parses JSON schema tool calls automatically.

 🛠️ Tech Stack
- Language:Python 3.14+
- LLM Engine:Groq API (`llama-3.3-70b-versatile`)
- Environment Management: `python-dotenv`
